# Entrega del Previo 2 — EcoEmprende

La guía docente exige cinco productos livianos, no la carpeta Library del editor.

1. Informe técnico PDF: portada, objetivos, mecánicas, 10 capturas reales del juego y resultados P1–P10, conclusiones.
2. Evidencias gráficas de menú, desplazamiento, colisiones, NPC, carteles, recolección, clasificación y HUD.
3. Video explicativo de 5 a 10 minutos con narración oral.
4. Build jugable comprimido para Windows o WebGL en itch.io.
5. Repositorio público GitHub con scripts, README y .gitignore (Unity).

No marques como realizadas pruebas sin ejecutarlas en Unity.
